# Analysis Mode Visibility

When a workflow supports different analysis modes, show the mode in both places:

- The editing control for the active group.
- The saved or recalculated result table.

Showing the mode only in the group editor is not enough because users read the
analysis table after calculation and need to know whether each row came from an
outside distance-band ROI or an inside polygon-area ROI.

Layer switching controls should also stay in a stable, prominent location near
the start of the image toolbar. When controls share the same segmented-button
visual style, their grouping and position must make the difference obvious.
